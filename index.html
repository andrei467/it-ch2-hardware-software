1. Mainframe Computers & Supercomputers

What counts as "hardware" and "software"?

Hardware is the physical, touchable parts of a computer system — the CPU, motherboard, RAM, ROM, graphics card, sound card, monitor, keyboard, mouse, printer, and so on. Software is the instructions that tell the hardware what to do: applications like word processors and spreadsheets, and the operating system that manages the hardware underneath everything else. Every program, whatever it looks like on screen, ultimately exists as binary instructions — long strings of 1s and 0s that the processor can carry out.

Key words

Device: a physical hardware component of a computer system.
Software: programs that give instructions to the computer.
Operating system: software that manages the hardware within a computer system.

Uses of mainframe computers

A mainframe computer can support thousands of connected terminals at once, which is why organisations like banks and large businesses rely on them. A terminal doesn't need much processing power of its own — even a cash machine (ATM) counts as one — because the real work happens back on the mainframe. This makes mainframes well suited to hosting business databases that huge numbers of customers and staff need to access simultaneously, and to running large-scale transaction and batch processing jobs, such as the statistical analysis behind a national census.

Key word

Mainframe computer: a powerful computer that serves several terminals at once.

Uses of supercomputers

A supercomputer is built for a completely different job. Instead of serving thousands of ordinary users, it's designed to run very few programs but push through enormous numbers of complex calculations as fast as physically possible, with (almost) all of its power aimed at one task at a time. This makes supercomputers essential for quantum mechanics research, where the behaviour of millions of atoms must be simulated, and for weather and climate forecasting, where detailed numerical models of the atmosphere, oceans, and land need to be calculated.

Key word

Supercomputer: a large computer that uses parallel processing to complete highly complex tasks quickly.

RAS: Reliability, Availability, Serviceability

Because so much depends on them, mainframes and supercomputers are designed around three qualities known together as RAS:

QualityWhat it means in practice
ReliabilityThe system is built so that it can be trusted to process data correctly and rarely fails. Hardware is extensively tested, and software is checked and updated quickly if problems are found.
AvailabilityThe system is designed to be running and reachable essentially 100% of the time. Redundant hardware (extra power supplies, extra components) automatically takes over if something fails.
ServiceabilityFaulty parts can be maintained or swapped out, sometimes while the system keeps running — this is called hot-swappable — so a repair doesn't force a full shutdown.

Measuring performance: MIPS vs MFLOPS

Mainframe performance has traditionally been measured in MIPS (millions of instructions per second). The problem is that MIPS isn't a very fair comparison: a CISC processor's single instruction might do far more work than a RISC processor's single instruction, so counting raw instructions can be misleading. Workload, cache size, and how much input/output activity is happening all affect the figure too.

For supercomputers specifically, performance is usually measured in FLOPS (floating point operations per second) or MFLOPS (millions of FLOPS), because scientific and mathematical calculations rely heavily on floating-point arithmetic, and different processors can need a different number of floating-point instructions to do the same calculation — so measuring the actual operations gives a fairer picture of real computing power than counting raw instructions.

Key word

FLOPS: floating point operations per second — used to measure the performance of supercomputers.

Why cold climates suit data centres

All that processing generates a lot of heat, so mainframes and supercomputers need serious cooling — either air cooling (which uses a lot of power to chill large volumes of air) or liquid cooling (which delivers cold liquid straight to the processor and is more efficient). This is exactly why many data centres are now built in naturally cold parts of the world: the surrounding cold air or water can do much of the cooling job for free.

2. System Software

Operating systems

System software is software designed to maintain or operate the computer system itself, and the most important example is the operating system. It sits between the hardware and any applications, and manages all the communication between the two.

Application
↕
Operating system
↕
Hardware

The operating system manages communication between applications and hardware.

Typical jobs an operating system carries out include:

  • allocating memory to software
  • sending data and instructions to output devices
  • responding to input devices, such as when a key is pressed
  • opening and closing files on storage devices
  • giving each running task a fair share of processor time
  • sending error messages or status messages to applications or users
  • dealing with user logons and security

Device drivers

The operating system can manage hardware in general terms, but it doesn't know the fine detail of every specific model of printer, graphics card, or scanner on the market. That's the job of a device driver: software supplied for a specific piece of hardware that translates the operating system's general instructions (like "print") into the exact commands that particular device understands.

Translators: turning source code into something the CPU can run

Programs are written by people in a high-level language, but the CPU can only execute machine code. A translator converts one into the other. There are two main types.

Compilers

A compiler translates the entire program (the source code) into an executable machine-code file (the object code) in one pass, before the program is ever run. Because the whole thing is translated in advance, the finished executable can afterwards be run directly by the processor without the compiler needing to be present.

Compilation: the whole program is translated once, in advance of execution.

Compilation happens in three broad stages: lexical analysis (stripping out spaces/comments and breaking the code into tokens — keywords, identifiers, symbols, and so on), syntax analysis (checking the tokens actually obey the rules of the programming language's grammar), and finally code generation (producing the machine code for the target processor).

Interpreters

An interpreter also converts high-level code into machine code, but line by line, translating and immediately executing each statement before moving to the next. This makes it well suited to testing code while it's being written, since it can report an error the moment it's reached, rather than only after an entire program has finished compiling. The trade-off is that it tends to run more slowly overall, especially inside loops, because the same lines get re-translated every time they're reached.

Linkers

Large programs are usually split into several modules, each compiled separately into its own object file. A linker combines those separate object files — and any library code the program needs, such as common mathematical or input/output routines — into a single, complete executable file.

3. Utility Software

Utility software is system software that performs a specific maintenance job on a computer, rather than running the whole system the way an operating system does. Some utilities come pre-installed with an operating system; others are installed separately.

Key word

Utility software: software that performs a specific maintenance task on a computer system.

Anti-virus (antimalware) software

Anti-virus software has two main jobs. First, an anti-virus monitor runs continuously in the background, watching for suspicious behaviour or known danger signs, so it can stop malware being run in the first place. Second, it can scan the system to check for viruses or malware that may already be present. If it isn't fully sure whether a file is safe, the safest response is often to place it into quarantine: an isolated area where the file can't run or spread, but also isn't deleted outright, so it can be checked more thoroughly before a final decision is made.

Backup

A backup utility creates a second copy of data or programs from storage. It can be run manually whenever a user chooses, or scheduled to happen automatically at set times. Users are usually able to choose which folders and files get backed up, and where the backup copy is stored, so that if the original data is lost or damaged, it can be restored.

Data compression

Compression utilities shrink the size of files — a single file, several selected files, or a whole folder — so they take up less storage space and transfer between locations more quickly. The trade-off is that a compressed file usually takes slightly longer to open again, since it first has to be decompressed.

Disk defragmentation

To understand why defragmentation matters, it helps to know a little about how a hard disk drive (HDD) stores data. A disk is divided into tracks, and each track is split into sectors; a read/write head moves across the spinning platter to read and write data. Whenever possible, a computer tries to store a file's data together, in the same or adjacent tracks, because that's the fastest arrangement — the read/write head has the least distance to travel.

Over time, as files are created, resized, and deleted, gaps appear in this neat arrangement. When a file grows and there isn't enough free space next to it, the extra data has to be written somewhere else on the disk entirely. Multiply this across thousands of files and the disk becomes fragmented: pieces of the same file scattered in different, non-adjacent locations. Opening a fragmented file then means the read/write head has to jump between multiple places on the disk, which is much slower than reading one continuous block.

A defragmentation utility fixes this by reorganising the disk so that each file's data is moved back together into one contiguous block, using free space and whole cylinders where it can. This reduces how far the read/write head has to travel and noticeably improves performance, especially once a system has been used heavily for a long time.
