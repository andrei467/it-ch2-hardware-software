1. Data Compression

Why compress data?

A data compression utility shrinks the size of a file (or a group of files, or a whole folder) so it takes up less storage space and can be moved from one place to another more quickly — over a network, by email, or on a USB drive. The trade-off is speed at the other end: because the data has to be unpacked again, a compressed file is slower to open than the original, uncompressed version.

Key word

Data compression: reducing the size of a file (or set of files) so it uses less storage space and transfers more quickly, at the cost of taking longer to open again.

Compressing the folder before attaching it would reduce its overall size, which could bring it under the 10MB limit and also make it upload and send faster. The trade-off is that once the teacher receives it, they will have to decompress (extract) the folder before they can open the files, and unpacking a compressed file takes a little longer than opening an uncompressed one.

2. Disk Defragmentation & Formatting

Storing data on a hard disk

A hard disk drive (HDD) has two main parts: the drive (the electronics that control everything) and the disk itself (the medium the data actually sits on). The disk is made of one or more spinning platters. An actuator arm swings a read/write head back and forth across each platter to reach the data it needs.

TermWhat it means
PlatterA circular disk coated in magnetic material, where the data is actually stored.
TrackOne of many concentric circles on a platter's surface.
SectorA small wedge-shaped division of a track — the smallest unit the drive reads or writes at once.
CylinderThe set of tracks that sit in the same position on every platter, stacked through the drive.
ClusterA group of sectors treated as one unit for storing a file.

Wherever possible, the drive tries to store a file's data within a single cylinder, because that requires the least movement from the actuator arm — and the arm's movement is the slowest part of the whole process.

Fragmented files

As a disk gets used, files are deleted, leaving gaps in the storage. When a file grows in size, it needs more space than it originally had, so if there isn't a big enough gap right next to it, the extra data has to be written somewhere else on the disk entirely. Once every nearby cylinder is full, files eventually have to be split across many small gaps scattered around the disk. This is fragmentation: when opening the file, the read/write head has to keep jumping to different locations, which makes the whole process much slower.

Key words

Fragmentation: when a file's data is split across scattered, non-adjacent areas of a disk.
Defragmentation: a utility that reorganises a disk so each file's data is moved back into one contiguous block, reducing how far the read/write head has to travel.

Formatting

Before a disk can be used for the first time, it must be formatted: this organises the surface into tracks and sectors so the drive knows where it can store data. Formatting a disk that is already in use wipes all the data on it and prepares the tracks and sectors again, exactly as if the disk were brand new.

Try it yourself

Question 2

A student's laptop has plenty of free storage space, but photo files that used to open instantly now take several seconds to load. Suggest which utility could help and explain how it would improve performance.

⚠ Have a go yourself before checking — don't just skip to the answer.
Model answer

A disk defragmentation utility would help. Even with free space available overall, the photo files' data may have become fragmented — split into scattered sectors across the disk — from being edited, resized, or having other files deleted around them over time. This means the read/write head has to move to several different locations just to open one photo, which is slow. Defragmenting the disk moves each file's data back into one contiguous block, so the head barely has to move and files open faster.

3. File Management

Managing files with utility software

File-management utilities give users more control over copying, moving, and organising files than they might get by dragging things around manually. A file-copying utility can let a user copy only certain file types (say, just the Word documents from a folder full of mixed content), and can copy files to a single destination or synchronise them across several storage locations or devices at once — so when a file changes in one place, it updates everywhere else too.

Some files are locked by the operating system and can't be removed using normal deletion. A deletion utility can override this, permanently removing files and folders so they can't be restored or accessed — useful for clearing out temporary files, or software that a user or the system no longer needs.

Key word

Synchronisation: automatically keeping copies of the same files up to date across multiple storage locations or devices.

Try it yourself

Question 3

A teacher edits lesson resources on a laptop at school and wants the same up-to-date files available on a home computer without copying them manually every day. Explain how a file management utility could solve this.

Model answer

A file-synchronisation utility would solve this by automatically keeping the files on both machines identical: whenever a file is changed on the school laptop, the utility detects the change and updates the copy on the home computer (often via a shared cloud storage location), so the teacher never has to remember to copy files across manually.

4. Custom-Written & Off-the-Shelf Software

Two ways to get software

Custom-written software is developed specifically for one client, built around their exact requirements. Off-the-shelf software is written for a general purpose and sold to a wide market — anyone can buy it at a fixed price, off a shelf or online.

Key word

Off-the-shelf software: general-purpose software already written and available for anyone to purchase.

Custom-written softwareOff-the-shelf software
One client covers the entire development cost, so it is expensive.Cost is spread across every customer who buys a copy, so it's much cheaper per user.
Takes a long time to design, build and test before the client can use it.Available immediately — the customer can start using it right away.
Built to meet the client's exact requirements, with no unnecessary features.May be missing features the customer needs, or include many they'll never use.

Question 4

A small dental clinic wants software to manage patient records and appointments in a very specific way. A school wants standard word processing and spreadsheet software for its staff. Suggest which type of software each should choose, and explain why.

⚠ Give it a genuine try first — then compare your answer below.
Model answer

The dental clinic should choose custom-written software, since its patient-record and appointment needs are specific to its own processes, and off-the-shelf software is unlikely to fit exactly. The school should choose off-the-shelf software, since word processing and spreadsheets are common, general-purpose tasks shared by almost every organisation, so ready-made software will already do the job at a much lower cost than commissioning something custom-built.
